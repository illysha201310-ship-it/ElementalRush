# Elemental Rush (Стихии)

Браузерный экшен-рогалик: соединяй стихии (огонь, воду, землю, воздух, а потом молнию, тьму, кристалл, кровь
и природу) в 70+ заклинаний. Играется прямо в браузере на компьютере и телефоне.

- **Компьютер:** WASD — ходьба, мышь — прицел, Пробел — рывок, Esc — пауза.
- **Телефон:** палец слева — ходьба, кнопка справа — рывок, атаки бьют сами.
- Рывок меняется от главной стихии: огненный след, волна прилива, таран, порыв ветра, молния, теневой шаг…

## Запуск
Открой `index.html` в браузере, или запусти локальный сервер: `python -m http.server` → http://localhost:8000.
